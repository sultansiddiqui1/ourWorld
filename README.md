# Our Universe & First Bloom 🌌🌸

A mobile-first love letter of a website. See [PLAN.md](PLAN.md) for the full roadmap.

```bash
npm install
npm run dev        # http://localhost:5173 (also on your Wi-Fi, for phone testing)
npm run build
```

All personal content lives in `src/content/` and `public/audio/`.
3D source files live in `blender/`; exported models in `public/models/`.
